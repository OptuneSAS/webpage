# Sandor Academy - Pagina Web (Entrenador de Porteros)

Pagina web de alto rendimiento para Sandor Academy, una academia de entrenamiento
mental y fisico para porteros y jugadores de campo, con sede en Lakeland, Florida.

## Diseno

- **Estilo:** Atlético, moderno, minimalista con acentos rojos de alto contraste
- **Tipografia:** Oswald (titulos) + Inter (cuerpo)
- **Framework CSS:** Tailwind CSS v3 (CDN)
- **Paleta:** Fondo blanco (#f9f9f9), rojo elite (#bc0100), gris obsidiana (#2f3131)

## Contenido

- `index.html` - Pagina principal (archivo unico con estilo inline + Tailwind CDN)
- `DESIGN.md` - Sistema de diseno completo (colores, tipografia, espaciado, componentes)
- `screen.png` - Captura de pantalla de referencia

## Secciones

1. **Hero** - Titulo grande con imagen de fondo a pantalla completa
2. **El Metodo Sandor** - Filosofia de entrenamiento: precision tecnica, movimiento explosivo, fortaleza mental
3. **Conoce al Entrenador** - Seccion de liderazgo con valores (consistencia, disciplina, pasion)
4. **Programas de Entrenamiento** - Field Player Private y Goalkeeper Private
5. **Probado al Siguiente Nivel** - Alianza con Lakeland United
6. **Voces de Padres** - Testimonios
7. **Contacto** - WhatsApp, llamada, Instagram
8. **Footer** - Redes sociales y copyright
